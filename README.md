## About The App

Contact App is my first mobile application developed using Flutter, designed to help users manage their contacts efficiently. This beginner-friendly project focuses on fundamental Flutter concepts including UI design, state management, local data storage, and user interactions. The app provides a clean and intuitive interface for adding, viewing, and organizing contacts with ease.

---

## Main Features

### Contact Management
- **Add New Contacts** - Create contacts with name, phone, and email
- **View Contacts List** - Browse all saved contacts
- **Contact Details** - View complete contact information
- **Delete Contacts** - Remove unwanted contacts
- **Contact Count Display** - Track total number of contacts

### User Interface
- **Clean Design** - Simple and user-friendly interface
- **Bottom Navigation** - Easy access to add contact form
- **Responsive Layout** - Adapts to different screen sizes
- **Smooth Animations** - Pleasant user experience

### Data Management
- **Local Storage** - Save contacts on device
- **Persistent Data** - Contacts remain after app restart
- **Real-time Updates** - Instant UI refresh when adding/removing contacts

## Installation & Setup

### Prerequisites
- Flutter SDK (version 2.0 or higher)
- Dart SDK
- Android Studio or VS Code
- Android/iOS device or emulator

### Installation Steps

1. **Clone the repository**
```bash
git clone https://github.com/yasen-edres/contact_App.git
```

2. **Navigate to project directory**
```bash
cd contact_App
```

3. **Install dependencies**
```bash
flutter pub get
```

4. **Run the app**
```bash
flutter run
```
